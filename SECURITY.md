# Политика безопасности

Не публикуйте сведения об уязвимости в открытом issue. Сообщите владельцу репозитория приватно через GitHub Security Advisory: **Security → Advisories → New draft security advisory**.

Укажите версию приложения, шаги воспроизведения и возможное влияние. Не прикладывайте реальные голосовые записи или другие персональные данные без необходимости.
