# Политика безопасности / Security policy

Не публикуйте сведения об уязвимости в открытом issue. Сообщите мне приватно через GitHub Security Advisory: **Security → Advisories → New draft security advisory**.

Укажите версию, шаги воспроизведения и возможное влияние. Я отвечу и проверю сообщение лично. Не прикладывайте реальные голосовые записи или персональные данные без необходимости.

Please do not disclose vulnerabilities in a public issue. Contact me privately through **Security → Advisories → New draft security advisory**. Include the version, reproduction steps, and potential impact. I will review the report personally. Do not attach real recordings or personal data unless strictly necessary.
