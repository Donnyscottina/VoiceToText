# Участие в разработке

Спасибо за интерес к VoiceToText. Перед крупным изменением лучше сначала открыть issue и кратко описать задачу.

## Локальная проверка

```powershell
dotnet restore
dotnet build VoiceToText.slnx -c Release
```

Перед pull request:

1. убедитесь, что сборка проходит без предупреждений;
2. проверьте запись, отмену по `Esc`, вставку русского текста и работу трея;
3. не добавляйте в Git модели `*.bin`, локальные настройки и содержимое `artifacts/`;
4. обновите README, если изменилось пользовательское поведение.

Используйте понятные небольшие коммиты. Для исправления ошибки приложите шаги воспроизведения, ожидаемое и фактическое поведение.
