# VoiceToText

[English](README.en.md) · **Русский**

Я сделал VoiceToText как быстрый и приватный голосовой ввод для Windows: удерживаете горячую клавишу, говорите — и текст появляется в активном приложении.

Приложение написано на C# и распознаёт речь полностью на вашем компьютере. Я не отправляю записи в облако, не собираю телеметрию и не сохраняю аудио. В основе — [Whisper](https://github.com/openai/whisper) через [Whisper.net](https://github.com/sandrohanea/whisper.net).

## Что я реализовал

- глобальный Push-to-Talk в любом приложении;
- русский и английский интерфейс;
- русский, английский и автоматическое определение языка речи;
- локальное распознавание и Unicode-вставку в активное поле;
- Vulkan-ускорение с автоматическим переходом на CPU;
- модели от быстрой `tiny` до максимально точной `large-v3`;
- видимый прогресс загрузки модели: процент, объём, скорость и ETA;
- отмену по `Esc`, индикатор микрофона и системный трей;
- последнюю расшифровку с отдельной кнопкой копирования;
- адаптивный тёмный интерфейс без блокировки окна при загрузке модели.

## Быстрый старт

1. Откройте [последний релиз](https://github.com/Donnyscottina/VoiceToText/releases/latest).
2. Скачайте `VoiceToText-win-x64.zip` и распакуйте архив.
3. Запустите `VoiceToText.exe`.
4. При первом запуске дождитесь загрузки модели. По умолчанию я выбрал `large-v3` — около 3,1 ГБ.
5. Поставьте курсор в нужное поле, удерживайте `F8`, говорите и отпустите клавишу.

`Esc` отменяет запись или распознавание. Закрытие окна оставляет приложение в системном трее.

> Windows может показать SmartScreen для неподписанной сборки. Если архив скачан с Releases этого репозитория, нажмите «Подробнее» → «Выполнить в любом случае».

## Настройки

В приложении можно выбрать:

- модель: `tiny`, `base`, `small`, `medium`, `large-v3-turbo` или `large-v3`;
- язык распознавания: автоматически, русский или английский;
- язык интерфейса: русский или English;
- входной микрофон и чувствительность от 100% до 500% (по умолчанию 250%);
- клавишу Push-to-Talk;
- перехват горячей клавиши;
- восстановление буфера после вставки;
- запуск и закрытие в трей.

Настройки находятся в `%APPDATA%\VoiceToText\settings.json`, модели — в `%LOCALAPPDATA%\VoiceToText\models`.

По умолчанию Push-to-Talk назначен на `F8`. Доступны F1–F24, клавиши цифрового блока,
навигации и мультимедиа. Если выбрать `Caps Lock`, короткое нажатие продолжит обычно
переключать регистр, а удержание будет использоваться для диктовки.

## Выбор модели

| Модель | Скорость | Точность | Примерный размер |
|---|---:|---:|---:|
| `tiny` | максимальная | базовая | 75 МБ |
| `base` | высокая | неплохая | 142 МБ |
| `small` | сбалансированная | хорошая | 466 МБ |
| `medium` | ниже | очень хорошая | 1,5 ГБ |
| `large-v3-turbo` | средняя | отличная | 1,6 ГБ |
| `large-v3` | минимальная | максимальная | 3,1 ГБ |

По умолчанию я выбрал `large-v3`. Если важнее скорость или не хватает памяти, я рекомендую `small`; `large-v3-turbo` — хороший компромисс для мощной видеокарты.

## Запуск из исходников

Понадобятся Windows 10/11 и [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0).

```powershell
git clone https://github.com/Donnyscottina/VoiceToText.git
cd VoiceToText
dotnet restore
dotnet run --project VoiceToText.csproj
```

## Сборка релиза

```powershell
.\scripts\publish.ps1
```

Скрипт создаст self-contained сборку в `artifacts\VoiceToText-win-x64`. Пользователю такой сборки не нужен отдельно установленный .NET.

## Решение проблем

**Горячая клавиша не работает в окне от администратора.** Windows не разрешает обычному процессу управлять повышенным окном. Запустите VoiceToText от администратора только для такого сценария.

**Распознавание медленное.** Выберите меньшую модель. Если доступен Vulkan, Whisper.net автоматически использует GPU; иначе работает CPU.

**Текст не вставляется.** Проверьте обычную вставку `Ctrl+V` в целевом поле. VoiceToText временно использует буфер и восстанавливает его примерно через 700 мс.

**Модель не скачивается.** Проверьте интернет и свободное место. Незавершённую загрузку приложение удалит и начнёт заново при следующем запуске.

## Разработка

```powershell
dotnet restore
dotnet build VoiceToText.slnx -c Release
dotnet run --project tests/VoiceToText.SmokeTest/VoiceToText.SmokeTest.csproj -c Release
```

Я держу проект небольшим: `Forms/` содержит UI, `Services/` — аудио, Whisper, хоткеи и вставку, `Models/` — настройки и локализацию. GitHub Actions собирает Windows-артефакт автоматически.
