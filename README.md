# VoiceToText

Локальный голосовой ввод для Windows. Удерживайте горячую клавишу, говорите — и распознанный текст появится в активном приложении.

VoiceToText написан на C# и работает полностью на компьютере: запись не отправляется в облачные API. В основе распознавания — [Whisper](https://github.com/openai/whisper) через [Whisper.net](https://github.com/sandrohanea/whisper.net).

## Возможности

- глобальный Push-to-Talk в любом приложении;
- русский, английский и автоматическое определение языка;
- локальное распознавание и автоматическая вставка Unicode-текста;
- ускорение через Vulkan с автоматическим переходом на CPU;
- модели от быстрой `tiny` до точной `large-v3`;
- отмена по `Esc`, история последних фраз и индикатор уровня микрофона;
- работа из системного трея и сохранение настроек;
- автоматическая сборка Windows-артефакта через GitHub Actions.

## Быстрый старт

### Готовая сборка

1. Откройте раздел **Releases** на странице проекта.
2. Скачайте архив `VoiceToText-win-x64.zip` и распакуйте его в обычную папку.
3. Запустите `VoiceToText.exe`.
4. При первом запуске дождитесь загрузки модели. По умолчанию используется `small` (около 466 МБ).
5. Удерживайте `Caps Lock`, говорите и отпустите клавишу. Текст будет вставлен в активное окно.

Для отмены записи или распознавания нажмите `Esc`. Закрытие окна по умолчанию оставляет приложение в системном трее.

> Windows может показать предупреждение SmartScreen для неподписанной сборки. Нажмите «Подробнее» → «Выполнить в любом случае», если архив скачан со страницы Releases этого репозитория.

### Запуск из исходников

Понадобятся Windows 10/11 и [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0).

```powershell
git clone <URL-этого-репозитория>
cd VoiceToText
dotnet restore
dotnet run --project VoiceToText.csproj
```

## Как пользоваться

1. Поставьте курсор туда, куда нужно ввести текст: браузер, мессенджер, редактор или IDE.
2. Зажмите настроенную клавишу Push-to-Talk.
3. Произнесите фразу и отпустите клавишу.
4. После локального распознавания текст автоматически вставится в выбранное поле.

В настройках можно выбрать:

- модель: `tiny`, `base`, `small`, `medium`, `large-v3` или `large-v3-turbo`;
- язык: автоопределение, русский или английский;
- клавишу Push-to-Talk;
- блокировку горячей клавиши для других приложений;
- восстановление текста в буфере обмена после вставки;
- поведение кнопки закрытия.

Настройки хранятся в `%APPDATA%\VoiceToText\settings.json`, модели — в `%LOCALAPPDATA%\VoiceToText\models`.

## Выбор модели

| Модель | Скорость | Точность | Примерный размер |
|---|---:|---:|---:|
| `tiny` | максимальная | базовая | 75 МБ |
| `base` | высокая | неплохая | 142 МБ |
| `small` | сбалансированная | хорошая | 466 МБ |
| `medium` | ниже | очень хорошая | 1,5 ГБ |
| `large-v3-turbo` | средняя | отличная | 1,6 ГБ |
| `large-v3` | минимальная | максимальная | 3,1 ГБ |

Для большинства компьютеров рекомендуем начать с `small`. Если важнее скорость — выберите `base`; если есть мощная видеокарта и нужна точность — `large-v3-turbo`.

## Сборка релиза

```powershell
.\scripts\publish.ps1
```

Готовая self-contained сборка появится в `artifacts\VoiceToText-win-x64`. Пользователю такой сборки не нужно отдельно устанавливать .NET.

Эквивалентная команда:

```powershell
dotnet publish VoiceToText.csproj -c Release -r win-x64 --self-contained true -o artifacts/VoiceToText-win-x64
```

## Решение проблем

**Модель не скачивается.** Проверьте интернет-соединение и свободное место. Удалите незавершённый файл `*.download` из папки моделей и запустите приложение снова.

**Горячая клавиша не работает в приложении от администратора.** Windows не разрешает обычному процессу управлять окном с повышенными правами. Запустите VoiceToText от администратора только для такого сценария.

**Текст не вставляется.** Проверьте, что целевое поле допускает обычную вставку `Ctrl+V`. На время вставки приложение использует буфер обмена и по умолчанию восстанавливает предыдущий текст через 700 мс.

**Распознавание медленное.** Выберите меньшую модель. Если драйвер поддерживает Vulkan, Whisper.net использует GPU автоматически; иначе приложение продолжит работу на CPU.

**Антивирус проверяет приложение.** Self-contained сборка содержит нативный движок Whisper и .NET runtime, поэтому она довольно большая и может дольше проверяться. Исходники и процесс сборки открыты в репозитории.

## Разработка

```powershell
dotnet restore
dotnet build VoiceToText.slnx -c Release
```

Основные каталоги:

- `Forms/` — интерфейс и настройки;
- `Services/` — запись аудио, Whisper, глобальная клавиша и вставка текста;
- `Models/` — настройки и данные истории;
- `.github/workflows/` — автоматическая проверка и сборка артефакта.

См. также [CONTRIBUTING.md](CONTRIBUTING.md) и [SECURITY.md](SECURITY.md).

## Приватность

Аудио обрабатывается в памяти и не сохраняется на диск. В интернет приложение обращается только при первой загрузке выбранной модели Whisper. Телеметрии и облачного распознавания нет.
